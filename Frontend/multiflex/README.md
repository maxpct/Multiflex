# Multiflex

Sitio de servicios de Multiflex, hecho con React (Create React App), JavaScript y CSS puro.
Es una sola página con todo escrito directo (sin estados, sin listas dinámicas).

## Cómo correrlo
1. npm install
2. npm start
3. Se abre en http://localhost:3000

## Carpetas
Cada parte del sitio es un componente dentro de src/components, con su .js y su .css:
- Barra    : el menú de arriba
- Portada  : el banner verde de inicio
- Servicios: las tarjetas de servicios
- Contacto : el formulario y los datos de contacto
- Pie      : el pie de página
